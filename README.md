# FocusAI

نظام بحثي أولي لقياس أداء الانتباه وربطه بعوامل يومية باستخدام التعلم الآلي.

## ما الذي تم تطويره؟
- اختبار انتباه عشوائي من 3 مهام.
- قياس الدقة والأخطاء ومتوسط زمن الاستجابة الفعلي بعد ظهور السؤال.
- جمع النوم ووقت النوم والاستيقاظ ووقت الشاشة والدراسة والاستراحات ووقت الاختبار.
- حفظ البيانات في CSV بدون اسم أو رقم هوية.
- مقارنة Logistic Regression وDecision Tree وRandom Forest.
- عدم عرض دقة مصطنعة عند عدم كفاية البيانات.
- تنبؤ تجريبي بمستوى الأداء بعد تدريب النماذج على بيانات فعلية كافية.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```

## ملاحظة علمية
المشروع نموذج بحثي/تقني وليس أداة تشخيص طبي. للحصول على تقييم ML قابل للدفاع أمام لجنة تحكيم، يجب جمع بيانات حقيقية كافية ومتنوعة قبل إعلان دقة النموذج.
